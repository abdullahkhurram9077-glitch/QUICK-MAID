## Brand & Style

This design system expresses domestic readiness, rapid response, and certified hygiene. Built for high-intent domestic emergencies (spills, pre-event turnover, sudden moves, Airbnb rapid resets), the aesthetic blends technical dispatch reliability with the warm reassurance of domestic care.

The overall movement fuses **Contemporary Utility with Crisp Tactility**:
- **Confidence over clutter**: Generous structural spacing counterbalances emergency anxiety.
- **Visual speed with domestic warmth**: Punchy, energetic indicators paired with calm, deep structural planes.
- **Physical reassurance**: High-clarity feedback loops, instant availability states, vetted-staff proof points, and visible hygiene metrics.

## Colors

The palette balances institutional hygiene, domestic calm, and energetic dispatch urgency:

- **Primary Teal (`#0D9488`)**: The anchor of cleanliness, clinical precision, and professional sanitation. Applied to core actions, verified badges, active steps, and primary interactive containers.
- **Secondary Saffron Amber (`#F59E0B`)**: Signals lightning speed, dynamic availability, dispatch timers, and urgent CTA accents. Keeps the experience vibrant, optimistic, and fast without the panic of error-red.
- **Tertiary Crisp Emerald (`#10B981`)**: The signal of verified hygiene, background-checked personnel, sanitized rooms, and secured payments.
- **Neutral Deep Slate (`#0F172A`)**: Provides foundational contrast for high-legibility headings, heavy-weight metrics, and high-trust structural footings.
- **Surface Accents**:
  - Light canvas: `#F8FAFC` base with `#FFFFFF` floating structural tiers.
  - Subtle teal tint fills: `#F0FDFA` for confirmed service states.
  - Urgent countdown tints: `#FFFBEB` for active dispatch alerts.

## Typography

Typography prioritizes approachable authority and instant legibility under pressure:

- **Display & Headlines (`Plus Jakarta Sans`)**: Rounded, geometric terminals create an inviting, human presence while bold weights communicate swift execution and structure. Letter spacing tightens proportionally as scale increases to avoid loose, floaty display text.
- **Body (`Plus Jakarta Sans`)**: Clean, tall x-height ensures easy readability for service inclusions, insurance clauses, and price transparency.
- **Labels, Badges, & Metrics (`Inter`)**: Utilitarian, pixel-sharp, and neutral. Used for dynamic arrival countdowns, pricing breakdowns, star ratings, and vetted authentication IDs.

## Layout & Spacing

This design system uses an anchored 12-column responsive fluid grid with strict content max-width bounds:

- **Desktop (>= 1024px)**: 12-column grid, max content width of `1240px`, `gutter` of `1.5rem` (24px), outer canvas `margin` of `2rem` (32px).
- **Tablet (768px - 1023px)**: 8-column grid, `gutter` of `1.25rem` (20px), outer margin `1.5rem` (24px). Hero widgets shift from side-by-side to stacked full-width priority panels.
- **Mobile (< 768px)**: 4-column grid, `gutter-sm` of `1rem` (16px), outer `margin-sm` of `1rem` (16px). Form components stack into step-by-step full-bleed cards.

**Rhythm & Spacing Application**:
- Use `space-xs` (4px) and `space-sm` (8px) for micro-alignments inside pills, badges, ratings, and input icon-to-text gaps.
- Use `space-md` (16px) for interior card padding, stack gaps between input fields, and compact review avatars.
- Use `space-lg` (24px) for major card interiors, booking widget section breaks, and modal margins.
- Use `space-xl` (40px) for layout container separation and inter-card grouping.

## Elevation & Depth

Visual hierarchy uses **Tinted Ambient Tonal Diffusion** layered over clean white base planes:

- **Level 1 (Subtle Lift / Interactive Tile)**:
  `box-shadow: 0 2px 8px -2px rgba(15, 23, 42, 0.05), 0 1px 4px -1px rgba(13, 148, 136, 0.04);`
  Border: `1px solid rgba(15, 23, 42, 0.08)`.
  Used on idle service selectors, trust chips, and inactive review modules.

- **Level 2 (Floating Action / Sticky Booking Module)**:
  `box-shadow: 0 12px 24px -6px rgba(15, 23, 42, 0.08), 0 4px 12px -2px rgba(13, 148, 136, 0.06);`
  Border: `1px solid rgba(13, 148, 136, 0.15)`.
  Used on the primary dynamic booking widget, pricing calculation summary, and floating emergency bar.

- **Level 3 (Emergency Alert / Modal Overlays)**:
  `box-shadow: 0 20px 32px -8px rgba(15, 23, 42, 0.16), 0 8px 16px -4px rgba(245, 158, 11, 0.12);`
  Border: `1px solid rgba(245, 158, 11, 0.3)`.
  Used for instant dispatch confirmation sheets, SOS countdown alerts, and live cleaner location trackers.

## Shapes

The interface embraces a balanced **Rounded (Level 2)** language:

- **Standard Containers (`rounded`, 0.5rem / 8px)**: Used for text input fields, dropdown trigger buttons, micro security tags, and service detail chips.
- **Card Units (`rounded-lg`, 1rem / 16px)**: Used for dynamic booking cards, cleaner profile modules, verified trust boxes, and customer testimonials.
- **Featured Panels (`rounded-xl`, 1.5rem / 24px)**: Used for hero booking enclosures, dispatch state banners, and sticky bottom sheets on mobile.
- **Status Pills (`rounded-full`, 9999px)**: Reserved for SOS countdown badges, active availability badges ("Cleaners arriving in 28 mins"), and verification checkmarks.

## Components

### Buttons
- **Primary Urgent Dispatch**: Background `#F59E0B`, text `#0F172A`, font weight 700. Features an embedded lightning or arrow icon. Hover shifts to `#D97706` with subtle scale transition (`transform: scale(1.02)`).
- **Secondary Safe Confirm**: Background `#0D9488`, text `#FFFFFF`, font weight 600. Used for scheduling standard checkouts and verified bookings.
- **Tertiary Ghost / Text**: Transparent background, text `#0D9488`, border `1px solid rgba(13, 148, 136, 0.2)`.

### Emergency SOS Countdown Badge
- Capsule-shaped pill with background `#FFFBEB`, border `1px solid #FCD34D`.
- Features an animated pulsating ping indicator (color `#F59E0B`) beside monospace-styled remaining minutes (e.g., `⚡ ARRIVAL GUARANTEE: 28:40`).

### Dynamic Booking Widget
- Framed in `rounded-xl` with Level 2 elevation and crisp `rgba(13, 148, 136, 0.12)` border.
- Segmented toggle at top: "Instant SOS (<45 mins)" vs "Schedule Ahead".
- Real-time pricing meter updating directly on selection without page reload.

### Security & Trust Badges
- Surface `#F0FDF4`, border `1px solid #BBF7D0`, icon color `#10B981`.
- Compact layout pairing an SVG shield checkmark with two-line micro text: "100% Insured & Bonded" / "Background Check Passed".

### Input Fields
- Height `48px`, border radius `0.5rem`, border `1px solid #CBD5E1`, background `#FFFFFF`.
- Focus state: border color `#0D9488`, with a soft glow ring `box-shadow: 0 0 0 3px rgba(13, 148, 136, 0.15)`.
- Icon prefixes for location (pin), room count (home), and arrival time (clock).

### Review & Testimonial Cards
- White background card with Level 1 elevation, featuring verified badge (`#10B981`), 5-star rating clustered in `#F59E0B`, and high-contrast client avatar.
- Time-stamp indicator displays real-time authenticity (e.g., "Verified 2 hours ago • Deep Clean Reset").
